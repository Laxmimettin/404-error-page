
# 404 Error Page

## Project Description
A custom, responsive 404 error page designed to inform users when a requested page cannot be found. It features a space-themed illustration, friendly error message, and a button to return to the homepage.

## Objectives
- Practice HTML5 semantic structure.
- Improve CSS layout and typography skills.
- Create illustrations using CSS shapes.
- Implement animations and hover effects.
- Build a responsive web page.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Gradients
- CSS Animations and Transitions
- Media Queries

## Features
- Large and attractive 404 heading.
- Custom CSS planet and orbit illustration.
- Animated floating planet and twinkling stars.
- Friendly error message.
- Back to Home button with hover effects.
- Responsive layout for mobile and desktop.
- Reduced-motion accessibility support.

## Project Structure
404-error-page/
├── index.html
├── style.css
└── README.md

## How to Run
1. Create a folder named `404-error-page`.
2. Create `index.html` and `style.css`.
3. Copy the corresponding code into each file.
4. Save both files in the same folder.
5. Open `index.html` in a web browser.

## Learning Outcomes
This project demonstrates the use of semantic HTML, CSS Flexbox, responsive design, gradients, pseudo-independent CSS shapes, animations, and interactive hover effects.

## Conclusion
The 404 Error Page provides a friendly and visually appealing way to handle missing pages while improving user experience and practicing fundamental front-end development skills.
